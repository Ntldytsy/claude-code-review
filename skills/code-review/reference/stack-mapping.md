# 技术栈映射 · 索引

> 配套 `playbook.md`。playbook §4 的分层验证按栈换成具体命令，**只读与本次审查对应的那一个文件**，不要整批加载。

| 栈 | 文件 | 命令实测情况（以各文件顶部状态行为准） |
|---|---|---|
| PHP（裸 PHP / Laravel / Symfony / CI4） | `stack-php.md` | 无任何命令实际运行过 |
| Node.js（Express / Nest / Fastify，JS/TS） | `stack-node.md` | 部分实测（node 22/18、eslint、tsc、madge、fastify）；pm2/docker/redis/Nest 未实测 |
| 纯 HTML / jQuery，无构建 | `stack-html-jquery.md` | 多数标「实测」，Apache 头 / CDN 未实测 |
| Vue 2（vue-cli 4 / webpack 4） | `stack-vue2.md` | 无实测记载，视为全部未运行 |
| Python | `stack-python.md` | 命令均已本机实测（Python 3.12 + pyflakes）；框架相关未覆盖 |

每个栈文件的结构一致：四类动作命令映射 → 本栈审查维度重点清单（可替换 workflow.js 中 DIMS 的 focus）→ 本栈特有的坑。

**置信度标签**：`confident` 可放心用 · `version-dependent` 依赖版本/配置，先在项目里确认一次 · `uncertain` 仅供参考。没实际运行过工具的栈，标签一律降为 `version-dependent`。

**诚实声明：这些命令并非都经过验证。** 内容来自 agent 产出加一轮事实核查（事实核查查出的错误已内联修正进各文件正文，不再保留「修正」块）。首次在某项目用到一条命令前先小范围验证；验证不了就在交接里说「未验证」，不要报「通过」。

## 为未列出的栈写映射（清单）

逐项（语法 / 静态 / 加载冒烟 / 逻辑验证）给出命令、预期退出码/输出、以及「这条抓不到什么」：

1. 语法：该语言的纯解析器（不加载依赖）；多文件/多页共享全局作用域时要拼接后再解析；管道尾部别接 grep 吞掉退出码。
2. 静态：未定义名 + 未用变量的 linter/类型检查；写明哪些规则默认不开、要不要装框架插件、老代码怎么先冻结基线只拦新增。
3. 加载冒烟：真加载入口一次（不 listen / 不连生产）；说明本栈是否有「循环依赖静默通过」「顶层副作用」这类假绿。
4. 逻辑验证：隔离环境（一次性库/内存库需与生产同引擎）+ 外部副作用全部打桩，并给出「桩真的生效」的自检。

写完后：每条命令自己跑一遍或打上 `version-dependent`；每个「修正」直接改进命令本身，不要堆在下面。
